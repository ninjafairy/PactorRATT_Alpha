# PK-900 Operating Manual — Format Decision

The PK-900 conversion follows the same pattern as the existing project docs and the DSP-2232 conversion: **chapter-split Markdown** plus a machine-readable command catalog. `PK232_HostMode_Reference.md`, `HostCommands - Trimmed.md`, and `Pactor_Chapter.md` already train later agents to look up Host mnemonics, defaults, hex, timing, and mode procedures in Markdown headings and tables. Matching that layout means a coding agent can treat the PK-900 files as a sibling corpus instead of learning a new schema.

**Rejected alternatives.** A single 392-page Markdown or plain-text dump is too large for reliable retrieval and buries the Appendix A dictionary inside page noise. HTML adds tags without helping command lookup. JSON/YAML-only extracts cannot carry the procedural prose (RS-232 autobaud, radio DIN/PTT/FSK wiring, packet timing, Pactor changeover) that later agents need to write driver code. Splitting only by PDF page would ignore the manual’s own chapter/appendix boundaries.

**Chosen layout.** Keep the full extracted text, cleaned and headed, split by manual chapter under `docs/pk-900-manual/`. Appendix A command entries are split again by first letter and formatted like `HostCommands - Trimmed.md` (`### Name`, Mode / Host / Default / Parameters / Description). `INDEX.md` is the AI entry point (device identity, file map, topic and command lookup). `commands.json` lists `{name, host, default, mode, params, description, pdf_page}` only when those fields appear in the extract — never invented. Cite `(PDF p.N)` on chapter headings and command entries so agents can return to the Word-distilled PDF.

**Why this helps code generation.** Serial and Host work need exact tokens (`Pt`, `HOST`, `AO`, `TXDELAY`, dual-port `n/n` defaults), baud rates, pinouts, and timing units. Chapter files give operating procedures; the letter-split dictionary and JSON catalog give fast command lookup. This operating manual only *mentions* HOST Mode — framing, CTL bytes, and Host I/O live in the separate Technical Manual — so those details are not fabricated here. Warranty, FCC reprint, shipping, and schematic/pictorial pages are stubbed; figure-only pages are marked rather than guessed.
